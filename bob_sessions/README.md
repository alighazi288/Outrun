# bob_sessions/

**Required for judging.** IBM checks this folder for evidence that we built with Bob IDE.
Every teammate adds a screenshot for **every** Bob task they run for this project.

## How to capture one (from IBM's participant guide)

1. In Bob IDE's chat panel, select **Tasks** to see your task list. (If you worked in several
   workspaces, select **All**.)
2. Open a task that belongs to this project. Check you're in the right workspace.
3. Select the **task header**. The task session consumption summary appears.
4. Take a screenshot of that summary.
5. Save it here and add one row to the Bob log in `docs/SUBMISSION.md`.

## File naming

```
bob_sessions/YYYY-MM-DD_<your-first-name>_<short-task>.png
e.g. bob_sessions/2026-09-29_ali_init-agents-md.png
```

Do it **right after** each task. Reconstructing 40 sessions the night before the deadline is
miserable, and the log in `docs/SUBMISSION.md` is what we turn into the technology statement.
